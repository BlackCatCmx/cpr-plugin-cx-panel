# Codex 额度面板

codex-proxy-rs 的独立管理页面插件，展示 OpenAI Codex OAuth 账号的额度、套餐和令牌中的套餐到期时间。额度条表示**剩余百分比**，用量越高，色条越短。

页面每 30 秒读取一次宿主已有数据。账号旁的刷新按钮调用宿主已有的额度刷新接口；点击状态标记会修改宿主账号的启用状态，停用后账号不再参与调度。套餐到期时间来自宿主保存的 ID Token，可能与实时订阅信息不同；缺少该声明时显示“未知”。插件从不把原始令牌返回给浏览器。

## 安装

本仓库每次推送 `main` 后，GitHub Actions 会构建 Linux amd64 安装包并发布为最新正式 Release。在 codex-proxy-rs 插件管理中选择 GitHub 来源，填写 `BlackCatCmx/cpr-plugin-cx-panel`，留空标签即可选择最新正式版。

首次更新到支持操作的版本后，在插件详情的“设置”中填写 CPR 管理员用户名和密码；密码在“敏感配置”中单独保存，不回显。插件使用宿主内部端口，优先读取 `CPR_SERVER_PORT`，否则默认 8080；若实际端口不同，在同一设置页填写“CPR 内部端口”。无需填写公网地址。

插件声明 `accounts` 和 `data` 两项权限：前者读取账号名称、套餐及 ID Token，后者只读已有额度。账号启停和主动刷新通过本机管理接口执行。`accounts` 在宿主中属于较宽的账号权限，安装时请核对来源和权限摘要。

当前按 codex-proxy-rs v3.15.2 的 SDK 和打包工具构建。后续宿主升级时，若插件仍兼容可继续使用；若合同变化，再更新插件依赖和代码。
