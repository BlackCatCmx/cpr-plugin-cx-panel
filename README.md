# Codex 额度面板

codex-proxy-rs 的独立管理页面插件，展示 OpenAI Codex OAuth 账号的额度、套餐和 accessToken 到期时间。额度条表示**剩余百分比**，用量越高，色条越短。

页面每 30 秒读取一次宿主已有数据，不触发令牌刷新。账号旁的刷新按钮通过宿主回调刷新额度；点击状态标记会修改宿主账号的启用状态，停用后账号不再参与调度。令牌到期时间直接使用宿主提供的 accessToken 到期时间，缺失时显示“未知”；剩余不足 3 天及已过期显示红色，3～5 天显示黄色，超过 5 天显示绿色。停用账号仅保留红色警示，其余显示灰色。

套餐与账号之间显示代理出口国家的圆形国旗，复用宿主已保存的有效检测结果；直连、未知地区或缺少旗帜资源时显示灰色地球圆标。旗帜使用与宿主相同的 circle-flags SVG，随插件打包，查看页面不发起代理检测或访问外部图片服务。

## 安装

本仓库每次推送 `main` 后，GitHub Actions 会构建 Linux amd64 安装包并发布为最新正式 Release。在 codex-proxy-rs 插件管理中选择 GitHub 来源，填写 `BlackCatCmx/cpr-plugin-cx-panel`，留空标签即可选择最新正式版。

插件无需填写管理员账号、密码或端口。账号信息、令牌到期时间和已有额度均通过宿主回调读取，不读取原始令牌；账号启停通过宿主内部 HTTP 分派复用原生管理接口。安装时请核对插件来源。

从保存过管理员密码的旧版升级时，在版本切换的设置中清除敏感配置 `admin_password` 后保存；普通配置可清空为 `{}`。

当前按 codex-proxy-rs v3.35.0 的 SDK 和打包工具构建，使用 RPC v7 和 management v2，宿主版本要求为 3.35.0 至 4.0.0 之前。源码构建需要 Rust 1.99.1 或更高版本。
